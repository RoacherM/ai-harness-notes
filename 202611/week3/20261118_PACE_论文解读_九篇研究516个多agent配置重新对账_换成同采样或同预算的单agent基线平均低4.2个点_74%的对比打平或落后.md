# 多 agent 到底赢在协作，还是赢在多抽了几次？把九篇研究的 516 个多 agent 配置重新对账：换成同等采样数或同等预算的单 agent 基线，平均低 4.2 个点，74% 的对比打平或落后

你大概见过这样的论文图表：一个由 5 个 agent 组成、辩论 3 轮的系统，准确率比单个模型高了好几个点，结论是「协作带来了提升」。但仔细想想，这个系统调用了模型 15 次，而对照组只调用了 1 次，还是贪心解码。如果让单个模型也抽 15 次再投票，或者把同样多的 token 都花在它自己的思考上，差距还在吗？这个问题在多 agent 圈子里一直有人提，但各篇论文控制的变量各不相同：有的匹配思考 token，有的匹配迭代步数，有的匹配 agent 数，有的只统计美元成本，结论自然五花八门。

内华达大学里诺分校的 **More Agents, More Samples, or More Thinking? Untangling Coordination, Ensembling, and Test-Time Compute in Multi-Agent LLMs** 做的是一次「对账」：把九篇已发表研究里的 516 个多 agent 配置按「对照组拿到了多少算力」重新分层，再看协作本身还剩多少收益。看完我的感受是：**这篇本身不跑新实验，也有不少统计上的保留，但它提供的「基线阶梯」和六维资源向量，几乎可以直接拿来当审 harness 对比、多 agent 编排论文时的检查表。** 结论也很清楚：对照组一旦拿到同等采样或同等预算，多 agent 平均是负收益。

## 核心摘要

作者把单 agent 基线分成四级：A 类是单次贪心；B 类是同样采样数、不通信的多次采样（如 k 次自洽投票）；C 类是匹配某个声明的资源维度（如思考 token 或迭代步数）；D 类是扫一条准确率对算力的帕累托前沿。资源用六维向量记录：思考 token、总 token、美元成本、延迟、采样数、工具和脚手架调用。从九篇研究里抽出 516 个多 agent 配置（531 行原始表格），结果是：对 A 类基线，358 个对比的平均差 −0.032，去掉贡献最多的一篇后接近零（−0.005）；对 B 类或 C 类基线，474 个对比平均 −0.042，多 agent 在 74% 的对比里打平或落后，三层 REML 模型在对数几率尺度上的合并估计是 −0.195（CR2 95% 区间 −0.320 到 −0.070），各种敏感性检验下保持为负；有 B 类和 C 类基线的研究里，9 篇中有 8 篇研究均值不为正。五篇同时报告两种基线的研究里，把对照从贪心换成采样，同一个多 agent 系统的优势平均缩水 0.038，五篇全部为负。作者给出的理论解释是：当所有 agent 看到的证据相同，通信不增加信息；要有正收益，需要证据分割、外部验证或跨模型的错误去相关。论文附带一份六项审稿检查表和开源的算力记账工具。

## 🎯 为什么这件事值得写

一个 N 个 agent、T 轮通信的拓扑大约消耗贪心基线 N·T 倍的 token 和推理成本。而我们早就知道，重复采样、多数投票和更长的推理链本身就能提高准确率，不需要任何通信。所以拿多 agent 和单次贪心比，测到的是「协作加多采样加多算力」的总和，协作本身的贡献被混在里面。

已有的控制性研究结论并不一致：在多跳问答上匹配思考 token，单 agent 能追平或超过多 agent 辩论；在工具使用环境里，多 agent 收益依赖任务可分解性，单 agent 准确率过了约 45% 之后转负；在 MMLU-Pro 上按帕累托前沿读取的可比算力下，辩论和混合 agent 又比自洽投票高 1.3 和 2.7 个点。作者认为这些分歧的主要来源是每篇论文控制了不同的资源维度，所以需要一个统一的记账框架。

这件事和 harness 对比审计是同一个问题的两个版本：在比较两个 harness 或两种编排时，你得先确认双方拿到的算力、采样数、工具调用和脚手架开销是否可比，否则「提升」可能只是多花了预算。

## 🏗️ 机制：基线阶梯、六维资源向量和三个命题

### 基线阶梯

| 类别 | 单 agent 基线 | 能支持的结论 |
| --- | --- | --- |
| A 类 | 单次贪心 | 收益和采样数、token 预算混在一起 |
| B 类 | 同样采样数、不通信（如 k 次自洽） | 隔离了采样数，但 token 和成本可能仍不同 |
| C 类 | 匹配一个声明的资源维度 | 在该预算下隔离了协作收益，其他资源可能仍不同 |
| D 类 | 扫描算力预算画帕累托前沿 | 看不同算力区间里谁占优，未必有唯一赢家 |

### 六维资源向量与四种核实状态

$$R=\langle R_{reason}, R_{token}, R_{cost}, R_{lat}, R_{sample}, R_{sys}\rangle$$

分别是思考 token、总 token（含提示和脚手架）、美元成本、串行执行延迟、采样或实例数、外部工具和系统提示开销。每篇研究的每个维度被作者编码为「严格控制」「近似匹配」「不匹配但有测量」「未报告」四种状态之一。一个刺眼的结果是：**九篇研究里没有一篇控制延迟。**

### 协作效应与采样缺口

作者定义在声明预算 B 下，通信架构和非通信基线的配对差 $\Delta_{comm}$，要求两者的资源消耗都落在 $[(1-\epsilon)B, B]$ 之内，$\epsilon \le 0.10$，防止通信系统只用了一小部分预算却去和吃满预算的基线比。再定义采样缺口：

$$\Delta_{gap}=(p_A-p_{sampled})-(p_A-p_{B_0})=p_{B_0}-p_{sampled}$$

多 agent 的准确率 $p_A$ 在式中抵消，所以它不包含任何多 agent 信息，只是一个检验：表面收益缩水，是因为基线被重复采样加强了。以 Choi 等人的 14 个模型和基准组合为例：单次贪心平均 0.670，5 次多数投票 0.747（+0.076），5 个 agent 两轮去中心化辩论 0.715。对贪心看辩论是 +0.045，对投票看是 −0.031，后者才是协作效应的上界。

### 三个命题（都是带明确假设的简化模型）

1. **冗余下无信息增益**：如果每个 agent 私有的证据在给定共享上下文后对答案没有额外信息，那么无论通信协议是什么，对话记录都不增加关于答案的信息。作者强调这是关于信息、不是关于计算：有限能力的模型在同一份证据上多算也会变好，通信只是花算力的一种方式，所以辩论和自洽在等 token 下谁更好是经验问题。
2. **A 类偏差、相关投票的方差膨胀、脚手架稀释**：单次抽样准确率高于一半时，多数投票会系统性高于单次，所以贪心基线对任何聚合多次抽样的系统都有偏；K 个两两相关系数为 ρ 的答案，有效独立答案数是 $K/(1+(K-1)\rho)$，例如 K = 5、ρ = 0.5 时只有 1.67；全历史通信协议的脚手架 token 随轮数平方增长，挤占每次调用的思考预算。
3. **从众到真相的阈值**：假设每轮通信中错误 agent 变对的概率为 $\tau_{i\to c}$，正确 agent 变错的概率为 $\tau_{c\to i}$，令 $\kappa=\tau_{i\to c}/\tau_{c\to i}$，则基线准确率高于 $p^*=\kappa/(1+\kappa)$ 时通信会降低每个 agent 的准确率。κ ≈ 0.82 对应 p* ≈ 0.45，和 Kim 等人报告的约 45% 阈值吻合，但作者明确说这只是参数化示例，原研究没有报告转移率，分段回归也没在抽取数据里找到断点，所以不据此宣称阈值存在。两个转移率可以直接从辩论记录里估出来，工具包里有对应命令。

由此推出三条可能的正收益路径：**证据分割**（各 agent 看到不同的证据）、**非对称验证**（一个误接受率很低的外部验证器，比如编译器、单元测试或数据库查询）、**跨模型错误去相关**（异质模型组降低 ρ）。

## 🧪 关键证据

### 语料

| 来源 | 纳入方式 | 控制的维度 |
| --- | --- | --- |
| Tran & Kiela | 初始五篇 | 思考 token |
| Kim 等 | 初始五篇 | 迭代步数，工具使用 |
| Jwalapuram 等 | 初始五篇 | 成本审计 |
| Choi 等 | 初始五篇 | agent 数匹配 |
| Wunderlich 等 | 初始五篇 | 帕累托扫描 |
| Ke、Yang、Zhang、Smit 等 | 七篇候选按四条书面标准筛出四篇 | 主要和自洽比，Yang 等匹配 16 次生成 |

初始五篇是为了覆盖不同算力维度挑出来的，不是系统检索，作者明确说不宣称完整。数值从原始 PDF 表格抽取，Tran & Kiela 的 336 个单元格逐个程序化核对，另对九篇做了 40 个对比的分层抽查，零差异。

### 按基线类别的主结果

| 类别 | 研究数 | 对比数 | 对比均值 | 研究均值 | 多 agent 领先比例 |
| --- | --- | --- | --- | --- | --- |
| A 类（单次） | 5 | 358 | −0.032 | −0.010 | 0.37 |
| A 类，去掉 Zhang 等 | | | −0.005 | +0.003 | 0.48 |
| B 类（同采样数） | 6 | 360 | −0.051 | −0.043 | 0.24 |
| C 类（同预算） | 2 | 114 | −0.012 | −0.024 | |
| B/C 合并 | 8 | 474 | −0.042 | −0.038 | 0.26 |

B/C 合并里多 agent 打平或落后的有 352/474（74%），只看 B 类是 275/360（76%）。作者提醒，这里没有逐个检查资源条件，所以这些比例是「基线帕累托支配多 agent」比例的上界。Zhang 等人一篇贡献了 516 个配置里的 180 个，研究均值最低（对 CoT −0.058，对自洽 −0.073）；去掉它后 A 类的研究均值会翻正，但 B/C 合并在所有加权方式下都保持为负。

### 采样缺口

| 研究 | 配对数 | 采样缺口 | 为负的比例 |
| --- | --- | --- | --- |
| Jwalapuram 等 | 107 | −0.033 | 95% |
| Zhang 等 | 140 | −0.016 | 79% |
| Smit 等 | 28 | −0.021 | 100% |
| Ke 等 | 29 | −0.042 | 86% |
| Choi 等 | 14 | −0.076 | 100% |

五篇全部为负，按研究等权平均 −0.038。

### 多层模型

在 B/C 合并上拟合三层 REML（对比嵌套在研究内，对数几率尺度，假设条目相关 φ = 0.50），估计 β = −0.195（SE 0.052，CR2 95% 区间 −0.320 到 −0.070，自由度 7.2，p = 0.0076）。只看 B 类是 −0.235；去掉 Zhang 等是 −0.145；去掉基线是「最大值」的 Jwalapuram 等是 −0.190。φ 从 0 到 0.90 变化时点估计稳定在 −0.194 到 −0.195；逐一剔除研究时在 −0.233 到 −0.145 之间且上界都低于零。只有在研究内不相交的基准之间人为假设 0.5 到 0.8 的统一相关时，上界才越过零。研究内异质性很高（I² = 93%）。

### 几个有代表性的细节

- **匹配思考 token（Tran & Kiela）**：96 个对比平均 −0.007，三分之一多 agent 领先。100 token 时多 agent 平均 +0.077，但原作者说明两边推理都被截断；从 500 token 起均值转负（约 −0.012），1,000 到 10,000 token 是 −0.023 到 −0.035。
- **匹配迭代（Kim 等）**：18 个对比平均 −0.042（SWE-bench Verified −0.017，Terminal-Bench −0.067），但每个对比只有 20 个实例。
- **成本审计（Jwalapuram 等）**：多 agent 的美元成本中位是贪心 CoT 的 8.1 倍（均值 27.1 倍，最高 225 倍）。对贪心 CoT 平均 −0.007，对 5 次自洽 −0.041，领先比例从 42% 降到 25%。在 GPT-5 的 SMFR（588 题）上，自动多 agent 框架得分 20.2% 到 63.0%、成本 427 到 9,239 美元，CoT 48.5%、CoT-SC 57.0%，而人工搭建的领域工具 Expert MAS 用 555 美元拿到 96.51%。
- **唯一的正例（Wunderlich 等）**：MMLU-Pro 上 Llama-3.1-70B，在帕累托前沿读出的可比算力下，辩论和混合 agent 比 10 次自洽高 1.3 和 2.7 个点，作者注明这不是精确的预算匹配，混合 agent 的提议者也是同一模型的副本。

## 🔬 最有意思的部分

**「多 agent 提升」很大一部分是采样。** Choi 等人的例子最直观：对贪心看辩论 +0.045，对投票看 −0.031，同一组数据，结论正负翻转，只因为对照组的强弱不同。采样缺口在五篇研究里全部为负，说明这不是个别现象。

**真正的大收益来自工具，不来自对话。** SMFR 上 Expert MAS 96.51% 对自动多 agent 框架最高 63.0%，成本还低一个量级。作者只把它当作单一基准、单一系统的观察，但它和命题里的「非对称验证」路径吻合：带外部检查的结构才可能让错的变对、对的不变错。

**一篇论文能左右整体结论。** Zhang 等人一篇贡献三分之一的配置，去掉后 A 类的研究均值就翻了号。作者把这件事摆在表里，而不是藏在附录，这本身就是一种可借鉴的报告习惯：做元分析或横向比较时，单个来源的权重必须显式检查。

**延迟没人控制。** 九篇研究零篇控制延迟，可多轮通信天然串行，在交互式 agent 场景里延迟往往比 token 更贵。

## 🤔 我的判断

定位：**证据综合与方法论文**，不跑新实验，贡献在记账框架、基线分级和审稿检查表。

亮点三条：

1. **基线阶梯加六维资源向量**，把「对照组拿到了什么」变成可编码、可审计的字段，可以直接套用到 harness 对比或编排对比上。
2. **采样缺口这个检验很巧**：多 agent 项在式中抵消，只衡量基线被加强了多少，几乎不需要额外假设。
3. **结论的保留写得很清楚**：命题都标明了假设，45% 阈值只作示例不作断言，比例是上界，异质性和选择偏差都摆在明面上。

问题与局限：

- **只有九篇研究，且非系统检索**，初始五篇是挑出来覆盖不同维度的，存在选择偏差；研究、匹配条件和基线类别部分重合，难以分离。
- **一篇研究占 180/516**，对 A 类结论影响很大。
- **φ 是假设的**，因为原研究没有条目级结果；研究内异质性 I² = 93%，合并估计应视为探索性。
- **部分对比样本很小**（Kim 等每格 20 个实例）；主分析里选用的多 agent 臂（Centralized、两轮辩论）是事先选定的，作者自己承认这是一个分析自由度。
- **Jwalapuram 等的基线行是跨条目最大值**，对多 agent 不利，作者做了剔除检验，但这类口径差异提醒我们原始论文的报告方式本身就不统一。
- **单作者工作**，结论依赖对他人表格的再抽取，虽然做了核对，复现和扩展还需要更多独立检验。

对工程的直接启发：第一，任何「多 agent 优于单 agent」或「新 harness 优于旧 harness」的内部结论，都至少补一个 B 类对照（同采样数投票或 best-of-N），最好再补一个 C 类对照（同 token 或同成本），并记录六维资源。第二，上多 agent 之前先问任务是否真的需要分割上下文、独立工具或私有状态，否则先把单 agent 的测试时扩展用满。第三，多 agent 流程里优先引入外部验证（测试、编译、查询），而不是增加辩论轮数；可以从记录里估错变对和对变错的转移率，判断通信在你的任务上是在纠错还是在从众。

一句话：比较两种编排之前先对齐账本，否则你测到的可能只是谁多抽了几次。
