# 做过一道基础题就涨三倍，再做五道却不再涨：具身持续学习卡在经验提取

你有没有过这种体验：给 agent 先跑几道简单题攒经验，再让它做难题，第一道经验进来效果立竿见影；于是你兴冲冲地多喂了五六条轨迹、多写了几份 skill 总结，结果曲线纹丝不动，甚至还抖了一下。大家把这叫 continual learning 或 self-evolving，可**多出来的经验到底去哪了？**

北大与北京通用人工智能研究院（BIGAI）这篇 **EmbodiedCLBench**（arXiv:2610.13021）把这个问题搬进了具身仿真：先做基础家务任务，再看 agent 能不能把学到的原子技能**重新组合**去完成没见过的复杂任务。四个 harness（OpenClaw、Claude Code、Codex、Hermes）乘两个模型，结论很一致：零样本几乎做不了高级任务，经验能把成功率从约 10% 拉到 30% 以上，但**经验条数从 1 加到 6，成功率不再上升**。看完我的感受：这篇把「持续学习可规模化」这件事，钉在了一个可复现的反例上。

## 核心摘要

EmbodiedCLBench 以**组合泛化**作为持续学习的可操作定义：agent 先在基础任务上积累经验，再去解需要组合多个基础类别技能的未见高级任务。任务分三层：TongSim 的原子动作（每个 3 步，如走近、看向、拿起）、基础任务（2 个原子动作，最短路径 6 步）、高级任务（2 到 4 个基础类别组合，主实验 4 个原子动作、最短路径 12 步）。共 268 个任务（168 基础 + 100 高级），覆盖 6 类家务、28 种原子动作、51 类物体。因为用的是动作更丰富的闭源版 TongSim，作者把每个任务离线化成**状态转移图**：每个节点是一个状态，配第一人称图像和候选动作（最优、次优、不可执行三类），BFS 求最短路径，再从路径节点扩展干扰分支，于是评测完全离线、确定、可并行。三种设置：零样本、ICL（两条基础任务完整轨迹留在上下文）、Skill Learning（只留 agent 自写的 Markdown 技能总结）。主表里高级任务零样本 3% 到 12%，ICL / Skill 普遍 25% 到 52%；最高是 Codex + GPT5.6-Terra 的 ICL 52%。四条发现：经验跨 harness 一致有效；随组合复杂度上升，增益稳定在约 30 个点；**1 条经验贡献了大部分提升，之后不再随样本数增长**；经验主要作用是减少 13% 到 20% 的不可执行动作。

## 🎯 为什么这件事值得写

持续学习基准已经不少，但几乎都在数字或符号环境里：知识密集型任务、Web / OS 自动化、长期模拟世界、技能库演化。具身基准也很多，覆盖感知、导航、操作、长程规划，却没有一个专门问「**能不能把以前学会的东西拿来解新题**」。

EmbodiedCLBench 的切入点是把抽象的「持续学习」变成可测量的「组合泛化」：基础任务就是 test-time learning 数据，高级任务是考场。它直接对 harness 开刀，四个主流 agent harness 同台，这对关注 skills 与 harness 设计的人很有参考价值。

## 🏗️ 机制：离线状态转移图评测

构建四步：

| 阶段 | 内容 |
| --- | --- |
| 环境 | TongSim 室内家居，动作丰富、未被大量用作训练数据，降低污染风险 |
| 任务生成 | 原子动作 → 基础任务 → 高级任务，描述由 Qwen3.7-Plus 生成并人工核验 |
| 建图 | 每节点一个状态 + 第一人称图像 + 候选动作；BFS 求最短路，扩展干扰路径 |
| 评测 | 多轮交互：看图与候选 → 选一个动作 → 跳到下一节点，直到到达目标或步数耗尽 |

步数预算 = 最短路径 + 冗余：测试阶段 +3 步，学习阶段 +6 步以便探索。指标就是成功率：

$$
\mathrm{SR} = \frac{1}{N}\sum_{i=1}^{N} c_i,\quad c_i\in\{0,1\}
$$

## 🧪 关键证据

**主结果（Table 1，高级任务成功率 %）。**

| Harness | 模型 | 基础零样本 | 高级零样本 | ICL | Skill |
| --- | --- | --- | --- | --- | --- |
| Hermes | Qwen3.8-Flash | 58.9 | 8.0 | 44.0 | 33.0 |
| Hermes | GPT5.6-Terra | 53.0 | 11.0 | 16.0 | 34.0 |
| OpenClaw | Qwen3.8-Flash | 50.6 | 5.0 | 35.0 | 38.0 |
| OpenClaw | GPT5.6-Terra | 47.6 | 12.0 | 39.0 | 22.0 |
| Codex | Qwen3.8-Flash | 52.4 | 4.0 | 34.0 | 33.0 |
| Codex | GPT5.6-Terra | 54.8 | 11.0 | 52.0 | 26.0 |
| Claude Code | Qwen3.8-Flash | 42.9 | 3.0 | 27.0 | 31.0 |
| Claude Code | GPT5.6-Terra | 51.8 | 9.0 | 31.0 | 25.0 |

ICL 与 Skill Learning 没有一致的胜负：Hermes + GPT5.6-Terra 上 ICL 只有 16%，Skill 有 34%；Codex + GPT5.6-Terra 上反过来，52% 对 26%。

**组合复杂度（Hermes + Qwen3.8-Flash，3 到 6 个原子动作）。** 零样本从 28% 跌到 4%；ICL 从 72% 跌到 42% 后趋稳，6 个原子动作时 ICL 32%、Skill 26%。相对零样本的增益最终稳定在约 30 个点。

**样本数（k = 0 到 6）。** 从 k=0 到 k=1，成功率由 8% 到 10% 跳到 28% 到 40%；之后四条曲线（2 harness × 2 方法）都只是上下波动，没有上升趋势。

**错误分析。** 有经验后，不可执行动作减少 13% 到 20%，最优动作明显增加，次优动作也小涨 3% 到 8%。Skill Learning 的行为变化幅度一致小于 ICL，但成功率并不更差。

**泼冷水。** 离线图评测把动作空间压成「多选题」，候选还由 LLM 生成，离真实连续控制很远；高级任务只有 100 个，单一配置下 1 个任务就是 1 个百分点，表内一些反差（如 Hermes + GPT5.6-Terra 的 ICL 16%）可能受噪声影响；只测了两个 backbone，也没给多次运行的方差。

## 🔬 最有意思的部分

1. **经验的边际收益几乎在第一条就用完了。** 这说明现在的 agent 从经验里提取的主要是「这个环境怎么交互」这类格式性知识（哪些动作能执行、先走近再操作），而不是随样本累积的、可组合的技能结构。
2. **经验主要是在「排雷」。** 成功率提升大头来自少选不可执行动作，留在可执行轨迹上就能在预算内走到终点。这与其说是学会了新技能，不如说是学会了环境的接口约束。
3. **原始轨迹与技能总结打平。** 和 [Learn2Play](./20261009_Learn2Play_论文解读_经验别急着蒸馏成规则_原始轨迹加好harness才学得会陌生规则.md) 的「原始轨迹更好」不完全一致，这里两者互有胜负，且技能总结引起的行为变化更小、更聚焦。经验表示该选哪种，很可能取决于模型与 harness 组合。
4. **harness 之间差距不大但远未饱和。** 作者明确把「为持续学习设计 harness」列为下一步方向。

## 🤔 我的判断

定位：**具身持续学习的测量基础设施**，贡献在于把组合泛化变成可离线复现的评测协议，并让主流 coding-agent harness 同台。

亮点三条：

1. 组合泛化作为持续学习的操作定义，清楚、可扩展、难度可控；
2. 状态转移图离线评测，确定、可并行、可逐步诊断（最优 / 次优 / 不可执行）；
3. 「1 条经验就饱和」的发现，直接指出当前经验管线的瓶颈在提取而不在存储。

问题与局限：多选式动作空间过于简化；样本量小、无方差；学习阶段只有基础任务，没有研究经验库长期累积后的检索与冲突；Skill 总结格式完全由 agent 自由发挥，缺少结构化技能表示的对照。

对工程的直接启发：**(1)** 别默认「多喂经验就更好」，先测 k=1 和 k=多 的差异，如果打平，说明你的经验管线只学到了接口约束；**(2)** 把「环境接口约束」（哪些动作在什么状态可执行）单独做成一份可校验的技能或工具描述，可能比堆轨迹更省上下文；**(3)** 技能总结与原始轨迹应当作为 harness 的可配置项做 A/B，而不是写死一种；**(4)** 评估持续学习时，加上错误类型分析，能区分「学会了技能」和「学会了避坑」。

一句话收束：**EmbodiedCLBench 证明经验确实能迁移到更难的组合任务，但今天的 agent 只会从第一条经验里榨出接口常识，真正可规模化的持续学习还没出现。**
