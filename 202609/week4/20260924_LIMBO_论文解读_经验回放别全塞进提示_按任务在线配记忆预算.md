# 经验回放别全塞进提示：按任务在线配记忆预算，最强基线准确率能砍八成推理费

你有没有过这种体验：lifelong agent 把过去成功轨迹一股脑塞进 prompt——DB 上 `k=16` 精度只涨一两分，费用却涨到 no-replay 的五六倍；换个弱一点的 backbone，又发现「不回放就崩」？UCSD / WVU 的 LIMBO（arXiv:2609.14138）把这件事钉成一个独立问题类：**inference-time memory allocation**——经验回放不是固定预处理，而是每次任务前要和 token / round / tool 预算一起选的可控资源。看完我的感受是：这正好接在 [ComposeCL](../week3/20260916_ComposeCL_论文解读_持续学习机制组合起来才扛得住百任务记忆.md)「机制要组合」和 [ACLArena](./20260923_ACLArena_论文解读_Agent多阶段后训练会忘_共享权重合并有取舍_LoRA专家路由更近Oracle.md)「后训练会忘」旁边——**不改权重、单遍在线，也能学会「这题该不该回放」**。

## 核心摘要

LIMBO 用双头 LinUCB 上下文老虎机，在每个新任务到来前联合选择记忆模式（`none` / `full` / `compressed` / `retrieved`）与计算预算（token、round、tool 档位）。它满足四条工程硬约束：黑盒（不碰权重）、单遍在线（无离线预训练）、每任务开销可忽略（CPU 上 <0.5 ms）、显式成本目标（λ=0.5）。在 LifelongAgentBench 的 DB + OS 各 500 任务、三条 backbone（Qwen2.5-7B、Llama-3.1-8B、GPT-4o-mini）上，LIMBO 落在每格的成本–精度 Pareto 前沿：相对该格最强固定记忆基线，准确率通常在 −3.8～+0.6 分内，**成本最高可降 ~83%，六格平均约 53%**。学到的策略按模型×环境分裂极狠——Qwen / GPT 的 DB 上约 **78%** 任务选 no-replay；Llama DB 则把约 **85%** 推到 retrieved，从 20.8% 拉回 66.2%。

## 🎯 为什么这件事值得写

Lifelong agent 的经验回放（把成功轨迹注入当前 prompt）已成为不调参也能「续本事」的默认手段。但回放并不免费：每条轨迹都和检索、推理、工具、校验抢同一截上下文与算力。LAB 上固定 `k` 的曲线很刺眼——Qwen DB 从 no-replay 到 `k=16`，精度大约 +2 分，费用却 >5×；`k=8→16` 几乎平坦。压缩（LongLLMLingua）省 token，却容易破坏交互环境需要的结构化动作痕迹；检索提高相关性，但仍吃上下文。

Byron 侧持续学习线已有 ComposeCL（机制组合扛百任务）与 ACLArena（多阶段后训练遗忘与专家路由）。LIMBO 补的是**推理时分配层**：不谈怎么存记忆，先谈**这题要不要花记忆、花多少预算**——对黑盒 API agent 尤其现实。

## 🏗️ 机制：双头 LinUCB 把回放变成动作

记忆库只保留成功会话 \(M_i=\{\sigma_j:j<i,y_j=1\}\)。动作同时指定模式与预算原语：

\[
m_i\in\{\text{none},\text{full},\text{compressed},\text{retrieved}\}
\]

| 模式 | 做什么 | 备注 |
| --- | --- | --- |
| none | 不注入历史 | 强 backbone + 低回放敏感环境的默认 |
| full | 最近 k 条成功轨迹原文（或 trimmed-trace） | LAB 标准基线；trimmed 保留动作语法 |
| compressed | LongLLMLingua 式问句感知压缩 | 易伤结构化动作 |
| retrieved | 从 64 条记忆库按相关性取 top-k | DB：指令 Jaccard + skill + 表 ID；OS 上 k=1 |

特征 \(x_i\in\mathbb{R}^{12}\) 在 LLM 调用前可算：prompt 形状（token 规模、skill 数等）、运行态 EMA（成本、准确率）、上一任务成败/出错。双头分别估正确率 \(\hat p_a=\sigma(\hat\theta_a^{\mathrm{acc}\top}x)\) 与归一化成本 \(\hat c_a=\max(\hat\theta_a^{\mathrm{cost}\top}x,0)\)，选臂：

\[
a_i^*=\arg\max_a\ \hat p_a(x_i)-\lambda\hat c_a(x_i)+\alpha\sqrt{x_i^\top A_a^{-1}x_i}
\]

观测 \(y_i,c_i\) 后 Sherman–Morrison 更新精度矩阵；\(d=12\)、\(|A|\le12\)，开销相对秒级 LLM 调用可忽略。

## 🧪 关键证据：六格 Pareto，策略分裂

Table II（三种子 42/43/44 均值）摘要：

| Model | Env | No-replay | 最强固定记忆基线 | LIMBO | 成本降幅 |
| --- | --- | --- | --- | --- | --- |
| Qwen2.5-7B | DB | 73.0 / $0.046 | Fixed k=16: 74.85 / $0.290 | 74.4 / $0.050 | **−82.8%** |
| Qwen2.5-7B | OS | 46.4 / $0.104 | Fixed trim k=1: 51.5 / $0.343 | 51.4 / $0.226 | −34.1% |
| Llama-3.1-8B | DB | 20.8 / $0.071 | Fixed k=16: 70.0 / $0.316 | 66.2 / $0.144 | −54.4% |
| Llama-3.1-8B | OS | 40.6 / $0.234 | Fixed k=1: 44.4 / $0.304 | 43.0 / $0.224 | −26.3% |
| GPT-4o-mini | DB | 66.4 / $0.283 | LongLLMLingua: 69.0 / $1.654 | 67.4 / $0.292 | **−82.3%** |
| GPT-4o-mini | OS | 59.0 / $0.783 | LongLLMLingua: 61.8 / $1.400 | 62.4 / $0.833 | −40.5% |

相对投票式 GSC，LIMBO 在四个匹配格上**更高准确、更低成本**（Llama DB 甚至 +26 分）。GPT-4o-mini OS 上严格 Pareto 压过 LongLLMLingua（+0.6 分、−40.5% 成本）。

学到的 action mix（同一控制器、同一超参）：

- **DB / 强模型**：≈78% no-replay + 最低生成档——回放只值 2–3 分却贵 5–6×；
- **Llama DB**：**记忆必需区**，≈85% retrieved，从 20.8% 救到 66.2%（距 fixed k=16 仅 −3.8 分、半价）；
- **OS**：偏 retrieved / full，比例随 backbone 变；
- Qwen OS 流上可看到在线学习：前 50 任务探索重，之后 retrieved 升到 ~73%；UCB bonus 从首 100 任务的 0.347 降到末 100 的 0.115（−67%）。

## 🔬 最有意思的部分

1. **问题重新定名**：不是「更好的记忆表示」，而是「记忆何时值得花」——可与 MemRL / SuRe 等表示层正交叠动作。
2. **策略不可全局手写**：同一套 bandit，六格政策质变；说明固定 `k` / 全局「总是检索」对 lifelong 部署是反模式。
3. **trimmed-trace > token 压缩**：保留可执行动作语法在交互环境里更值钱——对 harness 里「轨迹怎么塞进上下文」是直接提醒。
4. **黑盒 + 单遍**：不需要 LoRA / 教师 / 离线重训，API agent 也能挂一层成本感知控制器。

## 🤔 我的判断

定位：**lifelong agent 推理时资源分配的控制层论文**，测量清楚、工程接口干净。亮点三：

1. 把 replay 从预处理改成每任务动作，并显式优化成本；
2. 六格 Pareto + 政策分裂，证据足够打脸「统一记忆策略」；
3. 与权重侧持续学习互补——ComposeCL / ACLArena 管「怎么不忘」，LIMBO 管「记了以后这次要不要掏出来」。

局限：LAB 只有 DB/OS；本地模型美元是标准化代理价；λ 与特征未做大消融；compressed 在部分流上几乎从未被选中。对 Byron（agent / harness / 持续学习）：**主循环里加一层「记忆模式 × 预算」bandit，比无脑加大 `k` 更像产品**——尤其 API 贵、任务异质时。

一句话收束：lifelong 不是把过去全贴进 prompt；**先学会这题该不该回放，再谈回放什么**。
