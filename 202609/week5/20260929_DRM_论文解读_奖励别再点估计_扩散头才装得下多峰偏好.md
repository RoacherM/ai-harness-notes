# 奖励别再点估计：扩散头才装得下多峰人类偏好，不确定拒绝与 LCB 才能用分布做决策

你有没有过这种体验：LLM-as-judge / reward model 给同一答打出一个分数，RLHF 就围着这个点爬；可标注者对「有用 vs 无害」、同一 rubric 的理解本来就拧着——Anthropic-HH 互评一致大约 **63%**，HelpSteer 系过滤后仍有簇状分歧。标量头、高斯头、分位数网格都在提交「输出分布族」假设，多峰一来就糊成单峰或一个点。清华 NLP 这篇 Diffusion Reward Models / DRM（arXiv:2609.33803）把奖励建模改写成条件密度估计 \(p(\mathbf{r}\mid x,y)\)：冻结 LLM 编码器 + 轻量 Diffusion Transformer 把头噪声解成奖励向量，不假设参数族；推理抽 \(N\) 个样本形成经验分布，可聚合成均值、方差或分位。看完我的感受：这直接服务 Byron 的 **LLM-as-judge / reward / evals 闭环**——和 [JEV-as-a-Judge](../week4/20260924_JEV-as-a-Judge_论文解读_自信就收下不确定就升级_决策裁判三分钱顶住强模型.md) 的「不确定就升级」、[DIAL](../week4/20260928_DIAL_论文解读_消掉位置偏差还不够_少量人工把多裁判偏好校准成人味.md) 的偏好校准、[GameArena](../week4/20260928_GameArena_论文解读_主观裁判太吵静态榜又饱和_用胜负当地面真值的对战评测台.md) 的可判定地面真值同桌：DRM 给的是 **分布侧** 的拒识与风险敏感聚合，而不只是换一个更强点估计。

## 核心摘要

DRM 用冻结 FsfairX-LLaMA3-RM-v0.1 编码器取末 token 隐状态 \(\mathbf{h}\)，再以约 12M 参数的 DiT 奖励头（hidden 384、3 block、6 head）建模 \(p(\mathbf{r}\mid\mathbf{h})\)。两变体：**DRM-Multi-8B**（ArmoRM 聚合多属性语料 569K，\(K=19\)，掩码去噪 \(\mathcal{L}_{\mathrm{denoise}}\)）；**DRM-Pref-8B**（Tulu3 偏好 273K，\(K=1\)，伪奖励边距 \(\Delta=1\) + \(\mathcal{L}_{\mathrm{denoise}}+\lambda_{\mathrm{BT}}\mathcal{L}_{\mathrm{BT}}\)，\(\lambda_{\mathrm{BT}}=0.5\)）。推理默认 DDIM 10 步、CFG \(\omega=7\)、\(N=32\) 样本。五基准平均：Multi **66.2**、Pref **65.8**；同数据同骨干下压过标量 ArmoRM（62.3）与分位头 QRM-Llama3.1-8B-v2（64.1），RMB Pairwise 达 **78.0 / 78.2**。分布验证：相对 HelpSteer2 重复标注，helpful 上 Wasserstein **0.804**（经验先验 / 全局高斯 / 点估计约 1.03）；人类评分极差增大时多峰比例 37.6%→55.5%→63.2%。拒识：覆盖率 100%→70% 时 PPE Correctness 均 +2.81、RMB 多项 +4.56～+7.31；LCB（\(\mu-0.4\sigma\)）在满覆盖 BoN 上相对均值稳定小幅增益。下游同初始化 PPO：DRM-Multi RLHF 在 Arena-Hard v2 **2.0**、MT-Bench **74.8**，高于 FsfairX（1.3 / 73.6）与 ArmoRM（1.0 / 71.5）。代码 / 权重：https://github.com/thunlp/DRM · https://huggingface.co/Teburile/DRM。

## 🎯 为什么这件事值得写

奖励模型三范式——判别式标量、生成式长文裁决、参数分布头（高斯 URM/DPL、分箱 DPRM、分位网格 QRM）——共享一个限制：**输出分布族被先验钉死**。人类偏好却是统计意义上的多峰：价值权衡、rubric 解读、文化差异都会在同一 \((x,y)\) 上撑开多个可辩护峰。把 \(p(r\mid x,y)\) 压成点，等于抹掉分歧与不确定性，下游只能点估计 RL 或点估计 BoN。

DRM 的主张不是「再造一个更大的 RM」，而是换头：**扩散式非参数条件密度**，让多峰可表达，并打开 **奖励轴 test-time scaling**（对固定候选加采样收紧估计）——标量 RM 没有这条旋钮。对 Byron 的 judge 栈：这补上「先 binary/code check，再校准结构化 judge」之后的一层——**当必须用学得奖励时，决策要能读分布，而不是只读均值**。

## 🏗️ 机制：冻结编码 × DiT 去噪头 × 双监督 × 分布聚合

**架构。** \(\mathbf{h}=\mathrm{Enc}(x,y)\) 离线预计算；DiT 头 \(\epsilon_{\theta}(\mathbf{r}_t,t,\mathbf{h})\) 经 adaLN-Zero 注入条件与时间步，预测噪声。CFG：训练时以固定概率丢掉 \(\mathbf{h}\) 换成可学习无条件向量。

**多属性回归。** 掩码去噪 MSE，只在已标注维上计损；推理用 all-one mask 一次采出完整 \(K\) 维向量（消融略优于按训练掩码多次采）。

**成对偏好。** 从噪声预测重建 \(\hat{r}_0\)，加 BT 损失 \(-\log\sigma(\hat{r}_0^{(w)}-\hat{r}_0^{(l)})\)，并保留去噪项；无绝对标签时用对称伪目标（优胜/落败差 \(\Delta\)）。附录 A：对随机 \(\hat{r}_0\) 做点式 BT，是分布级胜率似然的上界型替代。

**推理。** DDIM 反向采 \(N\) 条 → 经验分布 → 聚合。主表用跨维均值标量以兼容标准 RM 协议；§4.2 另用不确定度拒识与 LCB。两条 test-time 轴：响应轴 BoN（与任何标量 RM 共享）；奖励轴加大 \(N\)（DRM 独有）。

## 🧪 关键证据

**匹配对照（Table 1）。** 同 ArmoRM 数据 + 同骨干：DRM-Multi avg **66.2** > ArmoRM 62.3 > QRM-8B 64.1；RMB Pairwise **78.0** 远超 ArmoRM 64.6。Pref 变体 avg 65.8，说明框架可在多属性与偏好两种监督间迁移。相对更大/闭源模型仍有竞争力（GPT-4o 67.7、Claude-3.5-Sonnet 68.5），但作者诚实承认未追上 Skywork-Reward-V2-Qwen3-8B（76.9）——数据与骨干规模差距在。

**细粒度。** RMB BoN 上 Helpful / Harmless 较均衡（差 <5）；JudgeBench Multi **58.6** 高于文中 GPT-4o / Claude 参考线；PPE Correctness **63.8**，MBPP 子项 65.3 等显示不只「文风讨好」。

**分布对齐人类分歧（Table 4–5，Figure 2）。** HelpSteer2：helpful 极差≥2 占 43.49%，分离簇 28.20%；DRM 在 Wasserstein / JS / L1 上全面优于全局先验与点估计。多峰率随人类分歧上升——模型不是学了一个全局「模糊」，而是按样本条件变多峰。

**分布感知决策。**  
- 拒识：按 \(U_{\mathrm{BoN}}=\hat{P}(r_{\mathrm{runner}}>r_{\mathrm{top}})\) 或对称 pair 不确定度剔最不确定样本，70% 覆盖下 PPE/RMB 明显涨。  
- LCB：\(\mu-0.4\sigma\) 在 PPE BoN \(N=2..32\) 与 RMB BoN 相对均值均正增益（满覆盖、不能弃权时仍有用）。

**Test-time scaling。** RewardBench v2：Multi 单样本 56.5% → \(N=32\) **65.6%**；Pref 64.4%→65.7%。PPE Correctness BoN 曲线上两 DRM 变体随候选数单调最好，部分基线大 \(N\) 反掉——点估计过优化苗头。

**RLHF（Table 3）。** 同 Tulu3-8B-SFT 初始化、UltraFeedback prompts、veRL PPO：DRM-Multi 作训练时奖励 → Arena-Hard v2 **2.0**、MT-Bench **74.8**，优于 FsfairX / ArmoRM 对照。

**效率。** 默认配置端到端约 **1.63×** FsfairX 延迟；\(S=5\) 可压到约 **1.38×**，Multi avg 仅 66.2→65.9。样本 \(N\) 并行，壁钟对 \(N\) 不敏感。

## 🔬 最有意思的部分

1. **多峰是统计事实，不是文风修辞。** 重复标注里的分离簇 / 极化直接证伪「分歧=独立噪声」；DRM 的多峰率随分歧走，是分布头该做的最小正确性检查。
2. **奖励轴 scaling。** 固定 \((x,y)\) 加采样就能抬榜——对 judge 服务是实在旋钮：贵查询多采，便宜查询少采。
3. **拒识与 LEV/JEV 精神同构。** [JEV-as-a-Judge](../week4/20260924_JEV-as-a-Judge_论文解读_自信就收下不确定就升级_决策裁判三分钱顶住强模型.md) 用决策不确定升级；DRM 用奖励样本重叠度拒识——可拼进同一「自信就收下」管线。
4. **LCB 是风险敏感 harness 的一行改动。** 不必改训练，推理聚合从 \(\mu\) 换成 \(\mu-\lambda\sigma\) 就能在 BoN 上挤出稳定增益——适合生产 Best-of-N。
5. **定性图（Figure 5）。** 同题上 DRM 多峰、ArmoRM 塌点、生成式 RM 因解码温度呈尖单峰——随机解码 ≠ 建模了奖励分布。

## 🤔 我的判断

定位：**把 RM 从点估计推进到非参数条件密度的范式样本**（测量 + 分布决策 + 初步 RLHF）。亮点三：

1. 匹配数据/骨干下明确赢标量与分位头，RMB 等协议增益大；
2. 用重复人类标注做分布距离与多峰–分歧斜率，不只报榜；
3. 拒识 / LCB / 奖励轴 scaling / 下游 PPO 把「有分布」变成「能用分布」。

局限：训练规模远小于工业 RM（数十万级 vs 千万级），绝对分未压 Skywork-V2 一线；固定 8B 编码器、缩放律未Sweep；扩散采样引入种子方差（附录显示 std 小但非零）；安全/偏见仍可能被高分风格绕过。对 Byron：

- Judge / RM 服务：**默认返回均值 + 方差/分位/多峰标志**，高不确定走升级（更强模型或人工），对齐 JEV；
- BoN / 门禁：试 LCB 或「top 与 runner-up 分布重叠」阈值，别只比均值；
- 训练数据若多属性异构，掩码统一空间 + 扩散头比硬塞单一标量更诚实；
- 与 [AdaTutoRank](./20260929_AdaTutoRank_论文解读_集合级标量奖励太稀_自适应辅导才把信用压到token.md) 合读：一边稠密化策略信用，一边让奖励本身携带分歧——闭环两侧都别塌成单标量；
- 与 [DIAL](../week4/20260928_DIAL_论文解读_消掉位置偏差还不够_少量人工把多裁判偏好校准成人味.md)：分布头降低「强制单峰」的信息损失，但仍需偏好校准防系统性偏置。

一句话收束：**人类偏好本来就是多峰分布，奖励模型却不该假装它是一个点**——扩散头先把分布装下，不确定拒绝与 LCB 再把分布用起来。
